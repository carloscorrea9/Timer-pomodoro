# Timer Pomodoro 

Um timer Pomodoro completo desenvolvido para meu portfólio, com foco em produtividade e personalização.  
Aqui você consegue configurar tempos de foco, descanso, horas planejadas de estudo e registrar um histórico real
do que foi cumprido.

---

## 🚀 Funcionalidades

- **Timer Pomodoro funcional**
- **Configuração personalizada**:
  - Tempo de foco
  - Tempo de descanso
  - Meta de horas de estudo
- **Histórico automático**:
  - Registra data
  - Registra quanto tempo de fato foi estudado
  - Permite adicionar registros manualmente
- **Interface simples e intuitiva**
- **Totalmente feito em HTML, CSS e JavaScript puro**
